- 树的节点为 0 时称为空树

- 子树：T树中某个节点为根，该节点及其所有后代节点构成的树
    * 注意：是所有，需要全部后代 *

- 度：节点相连的边的数量（有向图中还会根据方向区分出度、入度）
    - 所有点的度之和 = 边数*2（一条边会被两端点算两次）
    - 有向图中 入度之和 = 出度之和 = 边数

- 树的度：树中所有节点的度的最大值

- 终端节点：叶子节点；非终端节点就是除了叶子节点以外的所有节点

- 双亲：父节点，某节点的 直接 上层节点

- 孩子：子节点，某节点的 直接 下层节点

- 兄弟：具有相同双亲的节点

- 祖先：根节点到该点路径上，除了该节点外的所有节点（即包含双亲）

- 子孙：该节点的所有后代节点

- 层次：根节点层次为 1，依次往下递增

- 深度：树中节点的最大层次

- 堂兄弟：双亲不同！层次相同的节点

- 有序树：孩子有先后次序，交换后就不是同一颗树了
    - 最经典的就是二叉树，二叉树需要区分左子树和右子树

- 无序树：孩子没有顺序，交换孩子位置仍然是同一颗树
```
    A
  / | \
 B  C  D
```

- 森林：若干颗互不相干的树的集合
    - 若干颗：一棵树不是森林
    - 像一棵树删了根之后多棵子树之间就是森林；逆向：森林加公共根节点就是一棵树

- 树的先根遍历：从左到右的顺序先根遍历根节点的每一颗子树
- 树的后根遍历: 从左到右的顺序后根遍历根节点的每一颗子树

- 森林的先根遍历：可以看作所有树有一个共同后根节点的大树的先根遍历
- 森林的后根遍历：同理
