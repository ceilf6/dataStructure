前置知识 - 完全二叉树：除了最后一层都满，最后一层优先填左边

nk: 有 k 个孩子的节点

# 性质
- n个节点的二叉树的分支数为 n-1
    因为除了根节点外(n-1个)每个节只有一个父节点，即一条分支

- 叶子节点 n0 = n2+1
    由上条得到 n= 分支数+1= (n1+2*n2)+1
    又因为 n= n0+n1+n2
    所以叶子节点 n0 = 2*n2+n1+1-(n1+n2) = n2+1

- 完全二叉树叶子节点 n0= ceil(n/2)
    编号大于 floor(n/2) 的一定是叶子
    这是因为 完全二叉树的 n1 只可能是一个或者没有（1个的就是当最后一层没有填满的交界处）

- 完全二叉树高 floor(log(n)) + 1
    等价于 ceil(log(n+1))

- 高度h的二叉树，最少h个节点，最多2**h-1个
    一条树 和 满树
- 上条的逆向：n个节点高度最大 n，最少 ceil(log(n+1))即完全二叉树的高度(即使最后一层没满完全二叉树和满树的高度也是一致的)

- 在同一颗二叉树中，不论是先序、中序还是后序，叶子节点的相对顺序是完全一样的

- 完全二叉树的第 k 层有 m 个叶子节点，
    那么就代表了第 k+1 层有 2*m 个位置空着（因为他们的父节点是叶子）
    所以总共有 2**(k+1)-1-2*m 

# 表示

1. 顺序定义：
- i 的父节点为 ceil(i/2)-1
    - i=0根节点没有父节点
- 对应不越界的前提下，i的
    - 左孩子 2*i+1
    - 右孩子 2*i+2
- 由上条得到
    i 奇为左孩子，有 i+1 的右兄弟
    i 偶为右孩子，有 i-1 的左兄弟


2. 二叉链表：
```
struct Node {
    Node *leftChild, *rightChild;
    ElemType data;
};
```

3. 三叉链表:
```
struct Node {
    Node *leftChild, *rightChild, *parent;
    ElemType data;
};
```
