- 路径：从一个节点到另一个节点之间的分支序列
- 路径长度：从一个节点到另一个节点经过的分支数目

- 树中A节点的路径长度：从根节点到A节点的边数目
- 树的路径长度：树中所有节点路径长度之和

- 路径 * 节点的权重值 = 带权路径长度
- 树的带权路径长度 = 树中所有节点带权路径长度之和

哈夫曼树：带权路径长度WPL最小的二叉树，又称“最优二叉树”

```
对于一段电文：
AADDBCAAABDDCADAAADDCDDBAACCA。其字符集合为：{A、B、C、D}，各个字符出现的频率(次数)是 W＝{12、3、5、9}。若给每个字符以等长编码：A(00)、B(10)、C(01)、D(11)。则电文代码的长度为：(12+3+5+9)*2=58。
因各字符出现的频率为{12/29、3/29、5/29、9/29}，化成整数为{12、3、5、9}，以它们为各叶结点上的权值，建立哈夫曼树，如图6-23所示，得哈夫曼编码为：A(0)、B(100)、C(101)、D(11)。它的总代码长度：12*1+(3+5)*2+9*3=54。
```

本质就是不断的出堆、合并然后再入堆，直到只剩一个树
    注意合并的时候是统一小的作为左子树还是大的作为左子树

- 哈夫曼树中n1=0, 没有度为1的节点
    因为构造的时候是不断贪心合并两个
    所以哈夫曼树只有度为 0 或 2 的节点
    在有 n 个目标节点也就是叶子节点的情况下，由于 n0 = n2+1 => n2 = n0-1，所以哈夫曼树最终有
        2n-1 个节点

- 哈夫曼树不唯一，但是 WPL 肯定一样是最小的

- 哈夫曼编码：左0右1
    从根节点到叶子的路径
    一定是前缀码
